Early build — personal assistant

ASI

A personal AI assistant app I'm building for myself: one place to ask, plan and get work done, with the final call staying with me.

  • RoleDesign & build
  • ScopePersonal app
  • StatusEarly build
  • AudienceMyself, for now

01Why

The work is scattered. The context goes with it.

Notes in one app, tasks in another, half-finished thinking spread across chat windows. Every tool is useful on its own and none of them knows what the others are doing.

ASI is my answer to that: a single assistant I open when I want to think something through, plan it, and then actually move — instead of re-explaining the situation to a new window every time.

02What it aims to be

One front door. A stop button that stays mine.

A

One front door

A single place to ask and pick up where I left off, rather than a tab per task and a memory that resets each time.

B

Plans before actions

The assistant says what it intends to do before doing it, so a wrong assumption shows up as a sentence I can correct — not as a finished result I have to undo.

C

The human keeps the call

The same rule as the rest of my work: the agent proposes, I approve. Anything irreversible waits for an explicit yes from me.

03Where it is now

Early, and growing in the open.

This is a first version, not a finished product. There is no public release yet and no download link — when there is, it will appear here first.

This page is intentionally short. I would rather describe what the app does once it does it, than promise a feature list it has not earned.

Curious where it's going? Ask me.

If you are building a personal assistant of your own, I am happy to compare notes on approval flows and where the guardrails belong.
