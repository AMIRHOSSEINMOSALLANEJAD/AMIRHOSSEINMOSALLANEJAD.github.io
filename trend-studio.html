Trend Studio

A YouTube trend finder and content-idea writer that runs entirely on the phone. It reads what is rising, ranks it, and hands the strongest topic to Gemini for angles worth filming.

  • RoleDesign & build
  • ScopeAndroid app + Python core
  • StatusEarly build
  • StackKotlin · Compose · Chaquopy

01The problem

Ideas are cheap. Evidence is not.

Most content ideas start from a hunch and get checked afterwards, if at all. Trend data exists, but it arrives as a list of titles with no sense of which one is worth the next four hours of filming.

The tool I wanted was narrow: show me what is actually rising, rank it before I look, and turn the winner into a few concrete angles — on the phone, without opening a dashboard on a laptop.

02What it does

Four steps, one screen. No dashboard.

A

Find what is rising

Trending topics come in through the YouTube Data API and are normalised into a single readable list, so the noise of raw results never reaches the screen.

B

Rank before reading

A scoring pass orders the candidates, so the list arrives sorted by strength instead of by whatever the API returned first.

C

Draft the angles

The chosen topic goes to Gemini, which returns content ideas — the framing and the hook, not just another title to stare at.

D

Keep it on the phone

Topics, ideas, shared links and settings persist in a local SQLite store. Nothing is sent to a backend I have to run.

03How it runs

Python in your pocket. Keys that never leave it.

The interface is Kotlin and Compose. The Python core — trends, scoring, idea writing, storage — runs on the device through Chaquopy, which means the app needs no server and works without a laptop nearby.

Both API keys (YouTube Data API and Gemini) are entered in the app and written to its private folder on the phone. They are never stored in the repository, so the source can be shared or archived without carrying credentials with it.
